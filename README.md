## Next.js SPA
Chapter 5 of Learning React with TypeScript Guidebook with exercises. This part creates a single page application using client and server components.

## Key learning

- Next.js is an app framework that supports RSCs
- Use React Server Components for simplicity and performance.
- Use 'use client' directive at the top of the file to define a client component.
- Create 'ColorModeToggle' client component to switch between light and dark color theme.


## Run the server

```bash
npm run dev
```
